구글 시트 연결하기 (약 15분)
=====================================================
이걸 해야 ① 모두의 선택 기록이 모이고 ② 연구 노트 통계가 보이고
③ 스페셜 엔딩의 상품 응모가 내 메일로 온다.

연결하기 전에도 게임은 그대로 돌아간다. 통계만 "아직 연결되지 않았어요"로 나온다.


─────────────────────────────────────────
1. 빈 스프레드시트 만들기
─────────────────────────────────────────
1) sheets.new 를 주소창에 치면 새 스프레드시트가 열린다.
2) 왼쪽 위 '제목 없는 스프레드시트'를 눌러 이름을 ORVIA 기록 으로 바꾼다.

   ※ 탭(기록 / 답변 / 응모)은 직접 만들 필요 없다. 코드가 알아서 만든다.
   ※ 각 탭에 들어가는 칸
      기록 : 시각 · 기기번호 · 선택 7개 · 엔딩 · 경로 · 버전 · 마지막 수치 4개 · 본분쟁
             (이름·학번·연락처는 절대 들어가지 않는다)
      답변 : 시각 · 답변 · 공개   ← '공개' 칸은 아래 7번 참고
      응모 : 시각 · 학번 · 이름 · 연락처 · 답변 · 상품지급일 · 삭제예정일


─────────────────────────────────────────
2. 코드 붙여넣기
─────────────────────────────────────────
1) 위 메뉴에서 [확장 프로그램] → [Apps Script] 를 누른다.
   새 탭이 열리고 '코드.gs' 라는 빈 파일이 보인다.
2) 거기 적힌 내용을 전부 지운다. (Ctrl+A / Cmd+A → Delete)
3) 게임 폴더의 apps-script.gs 파일을 열어 전체를 복사해서 붙여넣는다.
4) 왼쪽 위 '제목 없는 프로젝트'를 눌러 이름을 ORVIA 로 바꾼다.
5) 디스크 모양 저장 버튼(또는 Ctrl+S / Cmd+S)을 누른다.


─────────────────────────────────────────
3. 웹 앱으로 배포하기
─────────────────────────────────────────
1) 오른쪽 위 파란 [배포] → [새 배포] 를 누른다.
2) 왼쪽 톱니바퀴 ⚙ → [웹 앱] 을 고른다.
3) 아래처럼 맞춘다.
      설명             : ORVIA
      다음 사용자로 실행 : 나
      액세스 권한이 있는 사용자 : 모든 사용자     ← 꼭 '모든 사용자'
4) [배포] 를 누른다.
5) '액세스 승인' 창이 뜨면 내 구글 계정을 고른다.
   "Google에서 확인하지 않은 앱입니다" 경고가 나오면
   [고급] → [ORVIA(으)로 이동] → [허용] 을 누른다.
   ※ 내가 만든 내 시트에 접근하는 것이라 안전하다.
6) 마지막에 나오는 '웹 앱 URL' 을 복사한다.
   https://script.google.com/macros/s/AKfycb................/exec


─────────────────────────────────────────
4. 게임에 주소 넣기
─────────────────────────────────────────
1) VS Code에서 data.js 를 연다.
2) 맨 위쪽 이 줄을 찾는다.

      const SHEET_URL = '';

3) 따옴표 사이에 아까 복사한 주소를 붙여넣는다.

      const SHEET_URL = 'https://script.google.com/macros/s/AKfycb..../exec';

4) 저장한다. 끝!


─────────────────────────────────────────
5. 잘 되는지 확인하기
─────────────────────────────────────────
1) 복사한 주소를 브라우저 주소창에 그대로 붙여넣고 열어 본다.
   {"ok":true,"total":0,...} 같은 글자가 나오면 성공이다.
2) 게임을 한 판 끝까지 해 본다.
   엔딩 화면 맨 아래에 "✓ 연구 노트에 기록되었어요" 가 뜨면 된다.
3) 스프레드시트로 돌아가면 '기록' 탭이 생기고 한 줄이 쌓여 있다.


─────────────────────────────────────────
6. 응모 정보 자동 삭제 켜기 (한 번만)
─────────────────────────────────────────
1) Apps Script 탭으로 돌아간다.
2) 위쪽 함수 목록에서 setupTrigger 를 고르고 [실행] 을 누른다.
   (처음 실행하면 권한 승인 창이 한 번 더 뜬다. 3번과 똑같이 허용하면 된다)
3) 이러면 하루에 한 번, '상품지급일' 칸에 날짜가 적힌 응모 정보 중
   1년이 지난 것을 자동으로 지운다.

   ★ 상품을 준 뒤에는 '응모' 탭의 '상품지급일' 칸에 날짜를 적어 두기.
     (예: 2026-11-20)  날짜를 안 적으면 지워지지 않는다.
   ★ 익명 플레이 기록('기록' 탭)은 지우지 않는다. 연구 노트 통계를 위해 계속 보관한다.


─────────────────────────────────────────
7. 좋은 답변을 연구 노트에 싣기
─────────────────────────────────────────
스페셜 엔딩에서 받은 답변은 '답변' 탭에 쌓인다.
그중 보여주고 싶은 답변만 골라서 연구 노트에 실을 수 있다.

1) '답변' 탭을 연다. 칸은 [시각] [답변] [공개] 세 개다.
2) 싣고 싶은 답변 줄의 '공개' 칸에 O 를 적는다. (아무 글자나 적어도 된다)
3) 1분쯤 뒤 연구 노트의 '✍️ 우리가 함께 쓴 답' 칸에 그 답변이 이름 없이 나온다.

· 아무것도 안 적으면 어떤 답변도 공개되지 않는다.
· 최대 12개까지 보인다.
· 이름·학번·연락처는 '답변' 탭에 없다 ('응모' 탭에만 따로 있다).


─────────────────────────────────────────
8. 배포 전 체크리스트
─────────────────────────────────────────
□ 친구들과 테스트하면서 쌓인 '기록' 탭의 줄을 모두 지우기 (첫 줄 제목은 남기기)
□ 스프레드시트 공유 설정을 '나만 보기'로 두기 (기본값이 그렇다)
□ 상품 응모 메일이 오는지 한 번 테스트해 보기
□ 바뀐 파일을 GitHub에 다시 올리기


─────────────────────────────────────────
자주 생기는 문제
─────────────────────────────────────────
· 주소를 열었는데 로그인 화면이 나온다
  → 3번의 '액세스 권한이 있는 사용자'가 '모든 사용자'인지 확인.
    고쳤으면 [배포] → [배포 관리] → 연필 아이콘 → 버전 '새 버전' → [배포]

· 코드를 고쳤는데 반영이 안 된다
  → Apps Script는 고친 뒤 [배포] → [배포 관리] → 연필 → '새 버전' → [배포] 를 해야
    반영된다. 주소는 그대로다.

· 게임에서 통계가 계속 안 보인다
  → data.js의 SHEET_URL이 '...../exec' 로 끝나는지 확인 (dev 가 아니라 exec)
  → 개발자 도구 Console에 빨간 글씨가 있는지 확인
